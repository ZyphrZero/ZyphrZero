# Toolbox SVG badges

The profile uses local SVG badges in the same 32px layout as the existing `go.svg`: a colored icon panel, a dark label panel, and a subtle gradient.

Existing `go.svg`, `python.svg`, `js.svg`, `react.svg`, and `docker.svg` are reused without changes. The additional badge containers and labels were created for this profile. Most imported glyphs are rendered in white; the Playwright glyph retains its original colors. The WPF badge uses the .NET mark to identify its platform.
