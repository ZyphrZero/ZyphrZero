## 🤖 AI agents & harnesses

**AI agents and agent harnesses are a long-term research interest of mine.** I keep studying their internals and experimenting with the systems that connect models, tools, context, and people.

- ⚙️ **Execution & orchestration** — agent loops, tool calls, approval boundaries, cancellation, and coordination across tasks.
- 🧠 **Context & memory** — context assembly, reusable skills, persistent state, and continuity across sessions.
- 🧪 **Reliability & feedback** — event traces, session replay, failure recovery, and tests that verify task completion.

I learn by reading source code, experimenting with agent runtimes, and bringing AI into everyday development workflows.
